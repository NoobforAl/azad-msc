04 · Memory · note 02

Four 9-bit indexes plus a 12-bit offset

SAY (EN): CR3 points to the PGD. Each level is a 4 KiB page of 512 entries. A PMD entry with PS set is a 2 MiB page, so the walk stops one level early — that is all a huge page is. SAY (FA): CR3 به PGD اشاره می‌کند. هر سطح یک صفحهٔ ۴ کیلوبایتی با ۵۱۲ مدخل است. مدخل PMD با بیت PS یک صفحهٔ ۲ مگابایتی است و پیمایش یک سطح زودتر تمام می‌شود؛ صفحهٔ بزرگ یعنی همین. KEY POINT: Linux code is 5-level generic; x86-64 folds p4d at boot without LA57. EXAMPLE: PGDIR_SHIFT is the variable pgdir_shift (39 or 48), arch/x86/include/asm/pgtable_64_types.h L50. PITFALL: Forgetting that under a hypervisor a miss is a 2-D walk (up to 24 reads). ASK: Which index bits select the PMD entry? TIME: 90

04 · Memory · notes 07–10

Four mechanisms decide who keeps memory

SLUB

per-CPU freelist, cmpxchg on (freelist, tid), no lock

Reclaim

kswapd at low watermark; MGLRU generations

Huge pages

one PMD = 2 MiB; 512× fewer faults

OOM killer

oom_badness = RSS + swap + page tables (+ adj)

Without swap, only file pages and slab can be reclaimed.

SAY (EN): Slab objects never appear in RSS. Reclaim drops clean file pages first. If nothing is reclaimable, oom_badness picks the largest footprint. SAY (FA): اشیای slab هرگز در RSS دیده نمی‌شوند. reclaim اول صفحه‌های فایلِ تمیز را دور می‌ریزد. اگر هیچ چیز آزادشدنی نباشد، oom_badness بزرگ‌ترین ردپا را انتخاب می‌کند. KEY POINT: Lab 04.5 grows dentry/inode caches by 200 000 files. EXAMPLE: slabtop -o -s c PITFALL: drop_caches as a tuning knob. TIME: 75

04 · Memory · walkthrough §9

Linux and OpenBSD split the fault differently

Linux v6.18.63

  • handle_mm_fault → handle_pte_fault
  • VMAs in a maple tree, per-VMA lock
  • COW: refcount + PageAnonExclusive
  • retry: VM_FAULT_RETRY

OpenBSD UVM 8cada8c

  • uvm_fault → upper / lower layer
  • map entries in an RB-tree, map lock
  • COW: anon->an_ref > 1
  • retry: ERESTART loop
SAY (EN): UVM keeps an explicit vm_anon per private page in an amap ("upper layer") above the backing uvm_object ("lower layer"). The COW test is a plain reference count, at sys/uvm/uvm_fault.c L1069. SAY (FA): UVM برای هر صفحهٔ خصوصی یک vm_anon صریح در amap نگه می‌دارد (لایهٔ بالا) که روی uvm_object پشتیبان (لایهٔ پایین) قرار دارد. آزمون COW یک شمارندهٔ ارجاع ساده است، در sys/uvm/uvm_fault.c خط ۱۰۶۹. KEY POINT: Same problem, different bookkeeping: UVM is easier to read, Linux uses less metadata per page. EXAMPLE: openbsd/sys/uvm/uvm_fault.c · uvm_fault() · L593 PITFALL: — TIME: 90

Reads of untouched anonymous memory map the zero page

"Use the zero-page for reads": one shared, read-only, zero-filled frame for every untouched page.

linux/mm/memory.c · do_anonymous_page() · L5169 · v6.18.63 — Lab 04.1 anon-read
