01 · Kernel design

Monolithic kernels call, microkernels message

SAY (EN): The design question is what runs in ring 0 and how the parts talk. Linux and OpenBSD put everything in one address space and use function calls; seL4 and QNX keep a tiny kernel and run the file system and drivers as processes. SAY (FA): پرسش طراحی این است که چه چیزی در ring 0 اجرا می‌شود و اجزا چطور با هم حرف می‌زنند. لینوکس و OpenBSD همه‌چیز را در یک فضای آدرس با فراخوانی تابع دارند؛ seL4 و QNX یک کرنل کوچک دارند و فایل‌سیستم و درایور را به‌صورت پردازه اجرا می‌کنند. KEY POINT: Cost = number of crossings; benefit = isolation. EXAMPLE: fs/read_write.c L569: file->f_op->read(...) is a plain function call into ext4. PITFALL: "Modules make Linux a microkernel." 01 · Privilege

A 2-bit number separates you from the kernel

Ring 3 · user
CS = 0x33catglibc[vdso]
syscall · IDT gate → CPL 0
Ring 0 · kernel
CS = 0x10entry_SYSCALL_64vfs_readschedule
Hardware
MSR_LSTARIDTCR3APIC

cli or mov %cr3 at CPL 3 → #GP → SIGSEGV.

SAY (EN): CPL is the low two bits of CS. In user mode CS is 0x33, which is GDT index 6 with RPL 3. The CPU checks CPL for privileged instructions, page U/S bits and IDT gate DPLs. The only way up is through doors the kernel installed. SAY (FA): CPL همان دو بیت پایین CS است. در حالت کاربر CS برابر 0x33 است، یعنی اندیس ۶ در GDT با RPL برابر ۳. CPU مقدار CPL را برای دستورهای ممتاز، بیت U/S صفحه‌ها و DPL گیت‌های IDT بررسی می‌کند. تنها راه بالا رفتن، درهایی است که کرنل نصب کرده است. KEY POINT: Linux uses rings 0 and 3 only. EXAMPLE: labs/02-raw-syscall/cpl.c prints CS = 0x33 and dies with SIGSEGV on cli. PITFALL: A mode switch is not a context switch. TIME: 90
01 · Entering the kernel

There are exactly three ways into ring 0

System call

Requested. syscall jumps to MSR_LSTAR; no IDT.

Exception

Synchronous. Fault (#PF, retried), trap (int3), abort (#DF).

Interrupt

Asynchronous. Device, timer (LOC), IPI (RES, CAL) via the APIC.

All three end in the same struct pt_regs on the task's kernel stack.

SAY (EN): A syscall is a request. An exception is caused by the current instruction. An interrupt comes from outside and can arrive between any two instructions. Exceptions and interrupts use the IDT; 64-bit syscalls don't. SAY (FA): syscall یک درخواست است. exception را دستور فعلی ایجاد می‌کند. interrupt از بیرون می‌آید و بین هر دو دستوری ممکن است برسد. exception و interrupt از IDT استفاده می‌کنند؛ syscall در حالت ۶۴ بیتی نه. KEY POINT: Same pt_regs format = one tracing/signal model for all entries. EXAMPLE: page-faults appear in perf stat, not in /proc/interrupts (lab 03). PITFALL: int 0x80 is the 32-bit legacy path, not how 64-bit Linux makes syscalls. TIME: 90
01 · The syscall path

read() crosses six steps and comes back the same way

1
glibc wrapper
eax=0; syscall
2
CPU
RIP=LSTAR
3
asm entry
pt_regs
4
C entry
do_syscall_64
5
dispatch
x64_sys_call
6
VFS
vfs_read

On the way out: signals, maybe schedule(), then sysretq.

SAY (EN): The wrapper loads the number and arguments into registers. The CPU jumps to the address the kernel stored in MSR_LSTAR. The assembly builds pt_regs. do_syscall_64 runs the entry work and dispatches through a switch. Then the VFS does the actual read. SAY (FA): wrapper شماره و آرگومان‌ها را در رجیسترها می‌گذارد. CPU به آدرسی که کرنل در MSR_LSTAR گذاشته می‌پرد. کد اسمبلی pt_regs را می‌سازد. do_syscall_64 کارهای ورود را انجام می‌دهد و با یک switch توزیع می‌کند. بعد VFS خواندن واقعی را انجام می‌دهد. KEY POINT: Arguments: rdi rsi rdx r10 r8 r9; result in rax; -errno on error. EXAMPLE: strace line: read(3, "aos-lab\n", 131072) = 8. PITFALL: The return path is a scheduling point. TIME: 90

SAY (EN): syscall does not touch rsp, so the kernel starts on the user's stack. It swaps GS, parks the user stack pointer, switches page tables if PTI is on, loads its own stack and builds the same frame an interrupt would push. SAY (FA): دستور syscall به rsp دست نمی‌زند، پس کرنل روی پشتهٔ کاربر شروع می‌کند. GS را عوض می‌کند، اشاره‌گر پشتهٔ کاربر را کنار می‌گذارد، اگر PTI روشن باشد جدول صفحه را عوض می‌کند، پشتهٔ خودش را بار می‌کند و همان قابی را می‌سازد که interrupt روی پشته می‌گذارد. KEY POINT: Long PER_CPU_VAR operands are shortened with "..."; full text in kernel-walkthrough.en.md §2. EXAMPLE: bash _shared/sources/cite.sh linux arch/x86/entry/entry_64.S L87 35 PITFALL: Pushing to the user stack would let other user threads read kernel data. TIME: 120

01 · Interrupts & exceptions

Exceptions and IRQs share the IDT; syscall doesn't

SAY (EN): Vectors 0 to 31 are CPU exceptions, 32 and up are devices and IPIs. Each gate has a DPL that decides whether user code may raise it with int N, and an optional IST stack for NMI, double fault and machine check. SAY (FA): بردارهای ۰ تا ۳۱ exceptionهای CPU هستند و از ۳۲ به بالا دستگاه‌ها و IPIها. هر gate یک DPL دارد که تعیین می‌کند کد کاربر می‌تواند با int N آن را فعال کند یا نه، و یک پشتهٔ IST اختیاری برای NMI، double fault و machine check. KEY POINT: Fault = retry the instruction; trap = continue after it. EXAMPLE: arch/x86/kernel/idt.c L84: def_idts[]; irq.c L318 common_interrupt. PITFALL: Calling every kernel entry a "trap". TIME: 90

01 · Context switch

A context switch swaps one stack pointer

SAY (EN): User registers are already in pt_regs. __switch_to_asm pushes only the six callee-saved registers, stores rsp in prev->thread.sp and loads next->thread.sp. CR3 changes only if next has a different mm. SAY (FA): رجیسترهای کاربر از قبل در pt_regs هستند. __switch_to_asm فقط شش رجیستر callee-saved را push می‌کند، rsp را در prev->thread.sp ذخیره و next->thread.sp را بار می‌کند. CR3 فقط وقتی عوض می‌شود که next یک mm دیگر داشته باشد. KEY POINT: entry_64.S L192: movq TASK_threadsp(%rsi), %rsp is the switch. EXAMPLE: kernel/sched/core.c L5333 switch_mm_irqs_off, L5349 switch_to. PITFALL: "The kernel saves all registers on every switch." TIME: 120

01 · Linux vs OpenBSD

Same hardware door, different policies behind it

Linux v6.18.63

  • read = 0 (per-arch table)
  • switch dispatch
  • error: -errno in rax
  • any address may syscall
  • no global kernel lock

OpenBSD 8cada8c

  • read = 3 (one MI table)
  • sysent[code].sy_call
  • error: errno + carry flag
  • pinsyscalls: libc call site only
  • KERNEL_LOCK() unless NOLOCK
SAY (EN): Both kernels start with swapgs, a scratch slot and the kernel stack, because the hardware forces it. Behind that, Linux optimizes for speed and compatibility, OpenBSD for a smaller attack surface. SAY (FA): هر دو کرنل با swapgs، یک خانهٔ موقت و پشتهٔ کرنل شروع می‌کنند، چون سخت‌افزار این را تحمیل می‌کند. پشت آن، لینوکس برای سرعت و سازگاری بهینه شده و OpenBSD برای سطح حملهٔ کوچک‌تر. KEY POINT: Full trade-off table in kernel-walkthrough.en.md §8.5. EXAMPLE: openbsd/sys/sys/syscall_mi.h L164: pin_check(p, code) PITFALL: Concluding one is "better" without naming the workload. Quick check

Which register carries the 4th syscall argument on x86-64 Linux?

A rcx, as in the C ABI
B r10
C on the user stack
D r11
SAY (EN): Twenty seconds. Think about what the syscall instruction itself does to registers. SAY (FA): بیست ثانیه. به این فکر کنید که خود دستور syscall با رجیسترها چه می‌کند. KEY POINT: Answer on the next slide. EXAMPLE: — PITFALL: — ASK: Who picked A, and why does it look right? TIME: 45
Answer: B

syscall already used rcx for the return address

rcx = user RIP and r11 = RFLAGS after syscall, so the kernel reads argument 4 from regs->r10.

linux/arch/x86/include/asm/syscall_wrapper.h · SC_X86_64_REGS_TO_ARGS · L56-59 · v6.18.63

SAY (EN): The wrapper macro decodes regs->di, si, dx, r10, r8, r9. libc moves the C ABI's rcx into r10 before the syscall instruction. SAY (FA): ماکروی wrapper مقادیر regs->di، si، dx، r10، r8 و r9 را می‌خواند. libc پیش از دستور syscall مقدار rcx در ABI زبان C را به r10 منتقل می‌کند. KEY POINT: r11 (D) is clobbered too: it holds RFLAGS. EXAMPLE: Lab 02 extension: raw mmap with the wrong register. PITFALL: Forgetting "rcx", "r11" in the inline-asm clobber list. TIME: 60
