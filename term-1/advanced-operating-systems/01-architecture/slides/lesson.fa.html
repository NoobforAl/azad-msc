۰۱ · ورود به کرنل

دقیقاً سه راه برای رسیدن به ring 0 هست

System call

درخواستی. syscall به MSR_LSTAR می‌پرد؛ بدون IDT.

Exception

همگام. fault (مثل #PF، تکرار)، trap (int3)، abort (#DF).

Interrupt

ناهمگام. دستگاه، تایمر (LOC)، IPI (RES، CAL) از طریق APIC.

هر سه به یک struct pt_regs روی پشتهٔ کرنل همان task ختم می‌شوند.

SAY (FA): syscall یک درخواست است. exception را دستور فعلی ایجاد می‌کند. interrupt از بیرون می‌آید و بین هر دو دستوری ممکن است برسد. exception و interrupt از IDT استفاده می‌کنند؛ syscall در حالت ۶۴ بیتی نه. SAY (EN): Request, synchronous exception, asynchronous interrupt; only the last two use the IDT on x86-64. KEY POINT: قالب یکسان pt_regs = یک مدل ردیابی و signal برای همهٔ ورودها. EXAMPLE: page-faults در perf stat دیده می‌شود، نه در /proc/interrupts (آزمایش ۰۳). PITFALL: int 0x80 مسیر قدیمی ۳۲ بیتی است. TIME: 90
