Lab 07.1 · What to observe

What to observe

  • 1
    Load moves the max, not the min
    min = fixed path; max = time the CPU couldn't switch
  • 2
    On a VM the host dominates
    ms spikes = vCPU descheduled; shape only
  • 3
    No /sys/kernel/realtime
    uname -v | grep -o PREEMPT_RT (init/Makefile L30)

Lab 07.1 · Common pitfalls

Common pitfalls

sched_setscheduler: Operation not permitted→sudo, or RLIMIT_RTPRIO in limits.conf
sched/preempt: No such file→mount debugfs; needs PREEMPT_DYNAMIC
tiny max on an idle box→always report the loaded run
SAY (EN): Symptom on the left, fix on the right; the README has the full table. SAY (FA): نشانه در یک سو و رفع در سوی دیگر؛ جدول کامل در README است. KEY POINT: Read the error message before searching. TIME: 60
