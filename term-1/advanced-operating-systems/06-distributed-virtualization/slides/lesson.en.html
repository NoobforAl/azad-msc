06 · Logical time

Lamport order is not causal order

Vectors decide: a → b ⇔ V(a) ≤ V(b) and V(a) ≠ V(b).

SAY (EN): Receive rule: L = max(L, Lm) + 1, V = max(V, Vm), then V[i]++. d gets L3 because m1 carried L2. a has a smaller L than g, yet nothing connects them: concurrent. SAY (FA): قاعدهٔ دریافت: L برابر max(L, Lm)+1 و V برابر max(V, Vm) و بعد V[i]++. رویداد d مقدار L3 می‌گیرد چون m1 مقدار L2 داشت. a از g کوچک‌تر است ولی هیچ مسیر علّی بینشان نیست: همروند. KEY POINT: a → b ⇒ L(a) < L(b), never the converse. EXAMPLE: Lab 06.1 counts such pairs in a real 3-process run. PITFALL: Sorting logs by Lamport time and calling it "causal order". ASK: Is f → h? 06 · Fault tolerance

The failure model sets the replica count

f + 1

crash-stop, failures detectable: one survivor holds the state

2f + 1

crash + agreement (Raft, Paxos): any two majorities overlap

3f + 1

Byzantine: honest replicas outvote f liars

Raft with 5 nodes: commit on 3, survive 2 crashes. FLP: no guarantee without timeouts.

SAY (EN): The same "tolerate one failure" needs 2, 3 or 4 machines depending on what a failure is allowed to do. SAY (FA): همان «تحمل یک خرابی» بسته به این‌که خرابی چه کاری مجاز است بکند، به ۲، ۳ یا ۴ ماشین نیاز دارد. KEY POINT: Quorums intersect: R + W > N. EXAMPLE: etcd and Consul run 3 or 5 Raft members. PITFALL: Two replicas cannot tell "peer crashed" from "network split". TIME: 90

1
System fd
open /dev/kvm
2
VM fd
KVM_CREATE_VM
3
Guest RAM
SET_USER_MEMORY
4
vCPU fd
KVM_CREATE_VCPU
5
Shared page

6
Loop
KVM_RUN

Guest RAM is anonymous memory of the VMM process; a vCPU is a thread blocked in KVM_RUN.

06 · Containers

A container's boundary is the syscall layer

SAY (EN): A VM's attack surface is the exit interface and the virtual devices. A container talks to the real host kernel through every syscall, /proc and /sys. One kernel bug reachable by a syscall breaks every container on the host. SAY (FA): سطح حملهٔ VM رابط exit و دستگاه‌های مجازی است. container با همهٔ syscallها و /proc و /sys مستقیم با کرنل واقعی میزبان حرف می‌زند. یک باگ کرنل که از راه syscall در دسترس باشد همهٔ containerهای میزبان را می‌شکند. KEY POINT: Namespaces = what you see; cgroups = how much you use. EXAMPLE: gVisor, Kata, Firecracker narrow the container boundary. PITFALL: "A container is a lightweight VM." TIME: 90

06 · Linux vs OpenBSD

OpenBSD isolates with promises, not views

Linux

  • KVM: in-kernel PIO/MMIO bus first
  • 8 namespace types, nested
  • cgroup v2: group limits
  • seccomp-BPF, imposed from outside

OpenBSD

  • vmm(4): every I/O exit goes to vmd
  • no namespaces, chroot only
  • per-process setrlimit
  • pledge/unveil, self-imposed
SAY (EN): vmx_handle_inout returns VMM_ACTION_ASSIST for every port access, so vmd emulates all of them. pledge_syscall is one AND against a static table per syscall. SAY (FA): تابع vmx_handle_inout برای هر دسترسی پورت VMM_ACTION_ASSIST برمی‌گرداند، پس vmd همه را شبیه‌سازی می‌کند. pledge_syscall برای هر syscall فقط یک AND روی یک جدول ثابت است. KEY POINT: Linux: features and speed. OpenBSD: less code in ring 0. EXAMPLE: openbsd/sys/arch/amd64/amd64/vmm_machdep.c L4801, sys/kern/kern_pledge.c L536 · 8cada8c. PITFALL: "No namespaces" does not mean "no isolation". TIME: 90
