05 · io_uring

Two shared rings replace syscalls

1SQ: user produces
2blocking → io-wq / poll
3CQ: kernel produces
SAY (EN): Each side writes only its own index, so no lock is needed. The kernel issues every request first with IOCB_NOWAIT on the same read_iter as read(2). SAY (FA): هر طرف فقط index خودش را می‌نویسد، پس قفلی لازم نیست. کرنل هر درخواست را اول با IOCB_NOWAIT روی همان read_iter که read(2) استفاده می‌کند اجرا می‌کند. 05 · Linux vs OpenBSD

Linux caches file pages; OpenBSD caches disk blocks

Linux v6.18.63

  • page cache per inode, any free RAM
  • hit: no fs call, no inode lock
  • RCU-walk path lookup
  • blk-mq + 4 schedulers
  • jbd2 journal

OpenBSD 8cada8c

  • buf(9) cache, bufcachepercent
  • ffs_read → bread(), vnode lock
  • locked VOP_LOOKUP walk
  • N-step SCAN, 128 per batch
  • no journal: fsck
SAY (EN): OpenBSD's read path takes the kernel lock and an exclusive vnode lock; it is simple and auditable but serializes readers. SAY (FA): مسیر read در OpenBSD قفل کرنل و قفل انحصاری vnode می‌گیرد؛ ساده و قابل‌بازبینی است ولی خواننده‌ها را پشت سر هم می‌کند. KEY POINT: sys/kern/vfs_vnops.c vn_read() L347, sys/ufs/ffs/ffs_vnops.c ffs_read() L216, sys/kern/kern_bufq.c. EXAMPLE: Walkthrough §9 trade-off table. PITFALL: "OpenBSD is slower" — it chose a different point on the simplicity/scalability curve. TIME: 90
