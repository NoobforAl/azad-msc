Entry code must not be traced before the kernel is ready

noinstr puts the function in .noinstr.text, which is compiled without ftrace hooks.

linux/include/linux/compiler_types.h · L417 · v6.18.63

SAY (EN): The kernel isn't in a state where tracing is safe at the very start of a syscall, so instrumentation is only allowed between instrumentation_begin and instrumentation_end. SAY (FA): در لحظهٔ شروع syscall، کرنل هنوز در وضعیتی نیست که ردیابی امن باشد؛ برای همین instrumentation فقط بین instrumentation_begin و instrumentation_end مجاز است. KEY POINT: An absence can be evidence. EXAMPLE: grep -w do_syscall_64 /sys/kernel/tracing/available_filter_functions → nothing. PITFALL: A (inlining) is false: it appears in /proc/kallsyms as a real symbol. TIME: 60
