Lab 00.2 · Common pitfalls

Common pitfalls

perf not found for kernel X→apt install linux-tools-$(uname -r)
bpftrace: BTF error→kernel without DEBUG_INFO_BTF → lab 03
perf_event_open: paranoid→sysctl kernel.perf_event_paranoid=1
