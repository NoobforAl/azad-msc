## Build notes

- **Colors:** the lab-deck generator hard-codes the root class `course-os`, but the slides only use the role classes `r-client / r-service / r-infra / r-store` (aliases of role-1…4 in the theme), so the Advanced SE mapping holds in the lab decks. The lesson decks use `course-se`.
- **Logo:** `_shared/brand/azad-logo.svg` is used if present; otherwise `azad-deck.js` shows the dashed `[University logo]` placeholder.
- **Real data only:** every command output on a slide comes from a real run on Windows 11 with Git Bash (2026-11-23). Cut lines are marked with `...`.
