m0 … m8 are names in your history, not tags in the course repo

1
Copy
cp -r project
2
Own repo
git init -b main
3
Gate

4

Each module ends the same way: commit, then tag m1, m2 … in your repository.

SAY (EN): The course repository holds project/ at its latest state and has no Git tags. You copy it out, make your own history, and tag your own m0. If a lab says start from m3, that is your m3, or the content of project/ at that point. SAY (FA): مخزن درس پوشهٔ project/ را در آخرین وضعیتش دارد و هیچ Git tag ندارد. آن را بیرون می‌برید، تاریخچهٔ خودتان را می‌سازید و m0 خودتان را tag می‌زنید. اگر آزمایشی بگوید از m3 شروع کن، منظور m3 خودتان است، یا محتوای project/ در همان نقطه. KEY POINT: A state is the content of project/ after a module; the tag is yours. EXAMPLE: git diff m0 m1 in your repository lists what module 01 changed. PITFALL: Working inside the course repository and then losing changes on the next update. TIME: 90

00 · Setup · quality gate

A copied project needs its own lint rules

BUG 
$ make lint
UP035 [*] Import from
  `collections.abc` instead
Found 9 errors.
make: *** [lint] Error 1

No config outside the course repo.

FIX 
$ cp ruff.toml .
$ make lint
ruff check analytics
All checks passed!

The rules live in the project.

If CI and your laptop disagree, the difference is the bug.

SAY (EN): Copying project/ out of the course repository leaves the repository's ruff.toml behind, and on ruff 0.17.6 the bare defaults flag nine things. The fix is to keep the lint rules inside the project, so every machine gets the same answer. SAY (FA): وقتی project/ را از مخزن درس بیرون می‌برید، ruff.toml مخزن جا می‌ماند و با ruff 0.17.6 تنظیمات پیش‌فرض نه مورد را گزارش می‌کنند. راه‌حل این است که قواعد lint داخل خود پروژه باشد تا هر ماشینی همان جواب را بدهد. KEY POINT: Put tool configuration in the project, not in your machine. EXAMPLE: Real output from lab 02 (Windows, Git Bash, 2026-11-23). PITFALL: Fixing the code to please a tool configuration nobody committed. TIME: 75

SAY (FA): این را با cite.sh از checkout خودمان چاپ کردیم، نه از حافظه. چیپ مسیر، تابع و pin را دارد تا هر کسی همان خط‌ها را باز کند. ارجاع به OpenBSD همین قالب را با commit به نام 8cada8c دارد.
