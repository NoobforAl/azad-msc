Lab 01.4 · Common pitfalls

Common pitfalls

bisect names an innocent commit→oracle returned 1 on build failure: use 125
go test passes on a bad commit→test cache: add -count=1
'../rel-v1.0' already exists→git worktree remove or prune
HEAD is detached afterwards→git bisect reset
SAY (EN): Symptom on the left, fix on the right; the README has the full table. SAY (FA): نشانه در یک سو و رفع در سوی دیگر؛ جدول کامل در README است. KEY POINT: Read the error message before searching. TIME: 60
