Lab 01.7 · What to observe

What to observe

  • 1
    Four of six commits fail
    style (S3, S4), provenance (T1, T2), tool behaviour (B1)
  • 2
    A script checks form, not meaning
    'add Count' and 'add stuff' both pass; review judges why
  • 3
    A hook fails at the cheapest moment
    seconds now vs a review round-trip later
  • 4
    Every number is a choice
    Linux says 70-75 characters; the checker says 72

Lab 01.7 · Common pitfalls

Common pitfalls

hook does nothing→chmod +x; name must be commit-msg; use Git Bash
python: command not found in the hook→edit the last line to python3
T2 fires on a correct-looking sign-off→name or email differs from git config
copying kernel sentences→quote a few lines with source; adapt the rest
