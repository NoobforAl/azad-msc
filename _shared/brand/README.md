# Brand assets

| File | What it is |
|---|---|
| `azad-logo.png` | Islamic Azad University emblem, 1280 × 1912 px, transparent background. **Unmodified download.** |
| `azad-logo.svg` | A wrapper that embeds `azad-logo.png` unchanged, so the decks' `…/azad-logo.svg` path resolves. It is **not** a redrawn vector. |

Colours sampled from the emblem: periwinkle `#647CD0`, navy `#283874` (they drive the theme tokens in `_shared/theme/azad-theme.css`).

## Provenance, read this before publishing

- Source: Wikimedia Commons, [File:Azad University logo.png](https://commons.wikimedia.org/wiki/File:Azad_University_logo.png), licence **CC BY-SA 4.0** (attribution + share-alike apply to the *file*).
- This is **not** a file from the university's own brand kit. The official site (`iau.ac.ir`) refused automated downloads (HTTP 403) and no public brand pack was found.
- The emblem itself is the university's mark. For a graded or official presentation, replace these two files with the copy the university or your faculty provides (same file names, nothing else changes).
- Keep the rules in `_shared/slide-design-system.md` section 3.2: never recolour, stretch, outline or animate the logo; place it on white.
